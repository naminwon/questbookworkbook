# Questbook Creator - 워크북 제작 플랫폼

React로 만든 교육용 워크북 제작 플랫폼입니다.

## 🚀 실행 방법

### 1단계: Node.js 설치 확인

먼저 Node.js가 설치되어 있는지 확인하세요:

```bash
node --version
```

Node.js가 설치되어 있지 않다면 [nodejs.org](https://nodejs.org/)에서 다운로드하세요.

### 2단계: 프로젝트 폴더로 이동

VSCode 터미널을 열고 프로젝트 폴더로 이동합니다:

```bash
cd 프로젝트폴더경로
```

### 3단계: 패키지 설치

다음 명령어를 입력하여 필요한 패키지를 설치합니다:

```bash
npm install
```

이 과정은 처음 한 번만 하면 됩니다. 몇 분 정도 걸릴 수 있습니다.

### 4단계: 개발 서버 실행

설치가 완료되면 다음 명령어로 개발 서버를 실행합니다:

```bash
npm run dev
```

### 5단계: 브라우저에서 확인

터미널에 나타나는 주소(보통 `http://localhost:5173`)를 브라우저에서 열면 앱이 실행됩니다!

## 🎯 주요 기능

- ✅ **워크북 제목 수정**: 제목을 클릭하여 직접 수정 가능
- ✅ **학교급 선택**: 초등학교, 중학교, 고등학교 선택
- ✅ **과목 및 학년 선택**: 학교급에 따라 과목이 자동으로 변경
  - 국어, 수학, 과학 선택 시 → 1, 2, 3학년 선택 가능
  - 다른 과목 선택 시 → 공통으로 자동 설정
- ✅ **학습 키워드 관리**:
  - 키워드 내용 수정
  - 키워드 삭제 (휴지통 아이콘)
  - 키워드 추가 (+ 학습 키워드 추가 버튼)
- ✅ **문제 유형별 문항 수 조절**: +/- 버튼으로 개수 조절
- ✅ **총 문항수 자동 계산**: 모든 문제 유형의 개수를 합산하여 표시
- ✅ **제작 언어 선택**: 한국어, 영어, 포르투갈어, 일본어 중 선택

## 📝 개발 팁

코드를 수정하면 자동으로 브라우저가 새로고침됩니다. (Hot Module Replacement)

개발 서버를 중지하려면 터미널에서 `Ctrl + C`를 누르세요.

## 🛠️ 사용 기술

- React 18
- Vite (빌드 도구)
- Tailwind CSS (스타일링)
- Lucide React (아이콘)
